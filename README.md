# השוואת רכבי 7 מקומות (ישראל, אוקטובר 2026)

אתר סטטי בעברית (RTL) להשוואת 8 רכבים משפחתיים עם 7 מושבים ומעלה: טבלת מפרט שניתן למיין ולסנן, השוואת תמונות בקנה מידה אחיד, מציג תלת־ממד ודף קרדיטים.

- אתר: https://dudidd-wq.github.io/cars-7seat/
- נתונים: `assets/data.js` (ציבוריים בלבד, נבדקו ב־20.10.2026 — מקורות בדף הקרדיטים)
- בנייה: `python3 src/build.py` (מייצר את קובצי ה־HTML מתוך `src/*.body.html`)
- מודלים תלת־ממדיים: Sketchfab, ‏CC BY 4.0 — ייחוס מלא בדף `credits.html`
- three.js r160 (MIT) נמצא בתיקייה `vendor/three`
